# Connecting to Splinter

## Pods 

The default, browser-based way to interact with Splinter. 

Go to `https://pods.science.ai.cam.ac.uk/` and enter the credentials you were given.

(*currently not available*)

## SSH

```bash
ssh <crsid>@splinter.cl.cam.ac.uk
```

Your SSH key must already be added to your Splinter account, and whitelisted.

If needed, specify a key:

```bash
ssh -i ~/.ssh/id_ed25519 <crsid>@splinter.cl.cam.ac.uk
```
