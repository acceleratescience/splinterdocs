# Server Specs

* The server is a high-performance GPU compute system running Ubuntu 24.04 LTS.
* It has 4 NVIDIA H100-class GPUs, 1 TiB of RAM, enterprise NVMe storage, and an Intel Xeon Gold CPU.

### CPU

* Intel Xeon Gold 6548N
* Server-class Intel Xeon processor

### GPU

* 4 × NVIDIA GH100 [H100L 94GB]
* 94 GB GPU memory per GPU
* 376 GB total GPU memory
* Matrox G200eW3 integrated graphics controller

### RAM

* 1 TiB total system memory
* 32 GB memory modules
* DDR5-5600
* Configured memory speed: 4400 MT/s

### Storage

* 2 × Dell DC NVMe ISE PE8110 RI U.2
* 1.92 TB per drive
* 3.84 TB total raw NVMe capacity

### Operating System

* Ubuntu 24.04.4 LTS
* Codename: Noble Numbat
